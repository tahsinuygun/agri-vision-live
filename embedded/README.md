# SmartFarm Embedded Challenge

TÜBİTAK 2237-A eğitimi için geliştirilmiş, mobil tarayıcıda çalışan interaktif gömülü sistemler uygulaması.

## Akış

- Sensör
- Mikrodenetleyici
- Karar
- Aktüatör

## Görevler

1. Toprak nemine göre sulama pompası kontrolü
2. Sıcaklığa göre fan kontrolü
3. Işık seviyesine göre aydınlatma kontrolü
4. Hatalı sensör verisini teşhis etme

Uygulama tamamen tarayıcı içinde çalışır ve herhangi bir kurulum gerektirmez.

## Eğitim

Bu uygulama, TÜBİTAK 2237-A “Tarımda Dijital Dönüşüm: Web Tabanlı Yapay Zekâ Uygulamaları Eğitimi” kapsamında Dr. Öğr. Üyesi Tahsin UYGUN tarafından hazırlanmıştır.
